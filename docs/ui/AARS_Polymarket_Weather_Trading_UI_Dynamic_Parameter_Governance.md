# AARS Polymarket Weather Trading Console
# UI Dynamic Parameter Governance

版本：v1.0  
日期：2026-04-25

## Principle

Dynamic UI fields must be generated by builders and policies. Frontend pages may render these fields, but must not independently derive operational meaning.

## Frontend Boundary

Frontend pages may:

- choose layout,
- render badges,
- show / hide expanded details based on already-provided contract fields,
- navigate with provided context.

Frontend pages must not:

- compute primary state,
- reinterpret gate result,
- compute execution permission,
- transform raw weather evidence into canonical fields,
- calculate opportunity score or quality score,
- decide execution-related action visibility without policy and gate context.
