# HMI UI Review Example

## Scenario

Review a monitoring page that hides the highest-risk items inside tabs and shows AI recommendations without evidence.

## Expected review shape

# Findings

1. [P1] Highest-risk items are not visible in the main view.
2. [P1] AI recommendations lack evidence, confidence, and boundary.
3. [P2] Disabled actions do not explain why they are blocked.

## Summary

The page should be reworked into a task-centered control surface with visible risk, explicit action gating, and transparent automation.
