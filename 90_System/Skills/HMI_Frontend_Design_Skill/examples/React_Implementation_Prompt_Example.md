# React Implementation Prompt Example

Use the Safety-Critical HMI Frontend Design Skill.

Task:
Design a current-task control page for a mission-critical monitoring console.

Constraints:

- show system status, current task, highest risk, data freshness, and latest stable view in the main layout
- keep alarms actionable and visible
- gate destructive actions with preconditions and confirmation
- show automation mode, evidence, confidence, and human override path
- expose degraded mode and recovery path

Output:

1. page HMI design spec
2. component list
3. data model
4. alarm and risk model
5. degraded mode and recovery handling
6. HMI review gate
7. React implementation prompt
