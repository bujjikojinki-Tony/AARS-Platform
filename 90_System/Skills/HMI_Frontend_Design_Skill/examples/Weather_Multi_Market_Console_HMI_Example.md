# Weather Multi-Market Console HMI Example

## Page purpose

Help an operator monitor multiple markets, understand weather-driven risk, and promote or suppress watchlist items with controlled actions.

## Task model

- primary task: identify the markets that need attention now
- secondary task: compare latest raw forecast with latest stable view
- secondary task: review model-market divergence
- secondary task: execute gated watchlist promotion

## Layout

- top bar: system status, data freshness, automation mode, highest risk
- left panel: market list and task list
- center panel: selected market situation
- right panel: alarm queue, divergence queue, recommendation queue
- bottom bar: latest stable view, recovery path, quick actions

## HMI review gate

- task fit: pass
- situation visibility: pass
- risk visibility: pass
- action clarity: pass
- action gate: pass
- alarm actionability: pass
- data trust: pass
- automation transparency: pass
- recovery: pass
- evidence: pass
