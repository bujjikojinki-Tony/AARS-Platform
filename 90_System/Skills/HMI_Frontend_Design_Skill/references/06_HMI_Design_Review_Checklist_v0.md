# 06 HMI Design Review Checklist v0

Source: `90_System/Guides/HMI/06_HMI_Design_Review_Checklist_v0.md`

## Review gates

- G1 task fit
- G2 situation visibility
- G3 risk visibility
- G4 action clarity
- G5 action gate
- G6 alarm actionability
- G7 data trust
- G8 automation transparency
- G9 recovery
- G10 evidence

## Dispositions

- Accept
- Accept with Minor Issues
- Defer
- Block
- Rework

## How this file is used

Read this reference when producing a formal UI review or when the user asks whether a design passes the HMI gate.
