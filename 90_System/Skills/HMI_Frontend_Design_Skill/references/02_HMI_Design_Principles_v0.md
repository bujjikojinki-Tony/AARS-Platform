# 02 HMI Design Principles v0

Source: `90_System/Guides/HMI/02_HMI_Design_Principles_v0.md`

## Stable rules

- task first
- situation aware
- alarm as action
- controlled action
- automation transparency
- degraded mode visibility
- consistency before novelty
- reviewable by design

## Main pattern

```text
Goal -> Situation -> Risk -> Action -> Evidence -> Verification -> Recovery
```

## How this file is used

Read this reference when designing or reviewing a page-level HMI flow.
