# Safety-Critical HMI Frontend Design Skill

This package turns the HMI cross-domain guideline set into an executable frontend-design skill.

## What it is for

- page and dashboard design
- UI review and HMI gate checks
- component and information-architecture specs
- alarm, degraded mode, and recovery design
- automation and AI recommendation surfaces
- Codex implementation constraints for frontend code

## Package layout

- `SKILL.md`: the executable skill instructions
- `templates/`: reusable page, component, review, and implementation templates
- `references/`: compressed rule summaries derived from the source HMI documents
- `examples/`: sample outputs for common HMI page types

## How to use

Ask Codex to use the skill when you want a page design, a review, or implementation guidance for a high-reliability frontend.

Example:

> Use the Safety-Critical HMI Frontend Design Skill to design a multi-market monitoring console. Include task model, layout, alarm handling, AI evidence, degraded mode, review gate, and a React implementation prompt.
