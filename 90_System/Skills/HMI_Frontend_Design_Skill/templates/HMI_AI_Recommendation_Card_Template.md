# HMI AI Recommendation Card Template

```yaml
recommendation_id:
recommendation:
reason:
input_data: []
evidence: []
confidence:
risk:
assumption:
boundary:
human_action_required:
audit_record:
```

## Display rules

- show mode and boundary first
- show evidence next to recommendation
- show confidence as a visible signal, not a hidden metadata field
- show human override or rejection path
- show what happens if the recommendation is not followed
