# Safety-Related Change Impact Analysis Template

## 1. Change Summary

- describe the proposed change
- identify the affected baseline

## 2. Affected Items

- requirements
- design elements
- logic / software
- HMI
- procedures

## 3. Safety Impact Screening

Check whether the change affects:

- safety function
- SIL / integrity claim
- safe state
- response time
- logic
- alarm / HMI
- bypass / override
- reset
- proof test
- device type
- software version
- parameter settings
- operating procedure
- maintenance procedure

## 4. Hazard and Risk Impact

- affected hazards
- affected unsafe scenarios
- changed assumptions

## 5. Requirements Impact

- changed requirements
- new requirements
- invalidated requirements

## 6. Design and Implementation Impact

- impacted architecture or logic
- impacted interfaces
- impacted operator behavior

## 7. Verification and Regression Impact

- required reviews
- required regression tests
- required traceability updates

## 8. Required Validation

- intended-use scenarios
- abnormal scenarios
- safe-state scenarios

## 9. Evidence Gaps

- missing hazard basis
- missing requirement basis
- missing review evidence
- missing validation evidence

## 10. Disposition

Use one:

- Pass
- Conditional Pass
- Hold
- Fail
- Insufficient Evidence

## 11. Required Actions

- action list
- owner
- due condition

## 12. Closure Conditions

- evidence needed for closure
- release conditions
