# Safety Review / Gap Analysis Template

## 1. Review Conclusion

Use one:

- Pass
- Conditional Pass
- Hold
- Fail
- Insufficient Evidence

## 2. Findings

For each finding include:

- title
- severity
- statement of issue
- why it matters

## 3. Brief Summary

- one short paragraph summarizing the current state

## 4. Satisfied Items

- items that are adequately covered by evidence

## 5. Missing Items

- missing evidence
- missing controls
- unresolved assumptions

## 6. Key Risks

- risk if proceeding now
- risk if left uncorrected

## 7. Required Evidence

- documents
- test evidence
- validation evidence
- baseline evidence
- independent review evidence

## 8. Corrective Actions

- action
- owner
- closure condition

## 9. Phase-Gate Recommendation

- recommendation
- gating rationale
- restrictions if conditionally proceeding
