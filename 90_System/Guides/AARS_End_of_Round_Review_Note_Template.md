# AARS_End_of_Round_Review_Note_Template

## 1. Purpose

This template provides the standard structure for recording an end-of-round review in AARS.

It is intended to:
- capture the final bounded review of a system round, project loop, or pilot loop
- summarize what was completed
- identify the stable anchor
- state the final decision clearly
- support closure, freeze, archive, and next-phase transition logic

This is an end-of-round review template.

Examples:
- `AARS_Round_01_End_of_Round_Review_Note.md`
- `Pilot_001_CDA_End_of_Round_Review_Note.md`
- `AARS_System_Baseline_End_of_Round_Review.md`
