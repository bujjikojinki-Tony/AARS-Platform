# AARS_System_Round_Charter_Template

## 1. Purpose

This template provides the standard structure for opening a bounded AARS system round.

It is intended to:
- define round identity
- define bounded objective
- define non-goals
- define what must be completed before closure
- make new rounds explicit and reviewable

This is a round charter template.

---

## 2. Recommended File Name

Examples:
- `AARS_Round_01_Charter.md`
- `AARS_Production_Readiness_Phase_1_Round_Charter.md`
- `AARS_Runtime_Prototype_Round_Charter.md`
