# AARS_Round_Closure_Note_Template

## 1. Purpose

This template provides the standard structure for recording the closure of a bounded AARS system-building round, project loop, or pilot loop.

It is intended to:
- record what round is being closed
- summarize what was completed
- preserve the current stable anchor
- state the final closure judgment
- define the bounded next move after closure

This is a closure-note template.

---

## 2. Recommended File Name

Examples:
- `AARS_Round_01_Closure_Note.md`
- `Pilot_001_CDA_Round_Closure_Note.md`
- `AARS_System_Baseline_Round_Closure_Note.md`
