# AARS_System_Round_Status_Note_Template

## 1. Purpose

This template provides the standard structure for tracking the current state of an active AARS system round.

It is intended to:
- make round progress visible
- preserve the current stable anchor for the round
- show what is completed, blocked, or still open
- support mid-round review and daily / weekly operation

This is a round status template.

---

## 2. Recommended File Name

Examples:
- `AARS_Round_01_Status_Note.md`
- `AARS_Production_Readiness_Phase_1_Status_Note.md`
- `AARS_Runtime_Prototype_Round_Status.md`
