# AARS_Validation_Context_Note_Template

## 1. Purpose

This template provides the standard structure for recording a chosen AARS validation context.

It is intended to:
- make the chosen validation context explicit
- preserve why it was selected
- state what it is expected to validate
- define scope and success conditions clearly

This is a validation-context note template.

Examples:
- `AARS_Round_02_Validation_Context_01.md`
- `AARS_Runtime_Prototype_Validation_Context.md`
- `AARS_Second_Pilot_Validation_Context.md`
