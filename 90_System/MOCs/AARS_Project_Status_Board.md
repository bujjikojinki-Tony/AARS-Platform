# AARS_Project_Status_Board

## 1. Purpose

This page is the project-status overview board for AARS.

It is intended to:
- show the current state of projects at a glance
- distinguish active, reviewable, conditionally stable, frozen, and archived states
- complement the project priority board with state visibility
- support multi-project governance with a simple readable dashboard

This page is a coordination/status page, not a governance model.

---

## 2. Use Rule

Use this page when:
- checking the current state of each project
- comparing active vs frozen vs archived condition
- deciding whether a project is ready for review, freeze, or recovery
- reviewing overall project maturity across the AARS system

Do not use this page as a substitute for local project review notes or stable-view notes.

## 6. Why This Board Exists

This board exists because:
- active-project pages show which projects are active
- priority board shows which project should receive attention first
- status board shows what condition each project is currently in

These are related, but not the same.
