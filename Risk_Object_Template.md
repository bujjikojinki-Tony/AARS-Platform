# Risk_Object_Template

## 1. Purpose

This template provides the standard structure for risk objects in AARS.

It is intended to:
- make risk bounded and explicit
- preserve origin, pathway, and consequence logic
- support review and continuity
- reduce vague or inflated risk statements

This is a risk object template.
