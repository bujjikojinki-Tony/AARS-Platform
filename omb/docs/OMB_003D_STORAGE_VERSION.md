# OMB-003D b9 数据库版本与回滚

裁决为 `READY_FOR_003D_TRANSACTION_REVIEW`。人工在场审批为 `BLOCKED_APPROVAL_PLATFORM`，003E～003G 为 `HOLD`。

## D4 到 D5

D5 沿用 D4 表结构，将 SQLite `user_version` 提升为 5。版本表示读取器须识别 `TASK_USABILITY_CHANGED`。b7、b8 读取器在检查事件前报告 `SCHEMA_VERSION_MISMATCH`，避免把版本差异误判为损坏。

`aars_task_manager.migration.migrate_d4_copy` 对已停止的 D4 库进行校验，分配单独的私有目标目录和数据库文件。迁移校验源格式、运行元数据、外键约束和历史链，在完成检查后生成 D5 副本。源文件只读。迁移拒绝活跃源、已有目标或完整性失败的来源。已有 B1、C2 和 D3 的升级入口也生成 D5 副本。

审批决定、审核、任务版本、审计事件及证据历史原样保留。新库生成新的数据库实例和分页密钥，清除旧运行标识。绑定在旧实例上的审批收据及挑战仍保留历史关联，无法在新实例提交或回放。

## 回滚

保留迁移前的 D4 文件及对应程序版本。回滚时停止 b9，恢复对应版本和原 D4 文件。含 b8 新事件的 D4 文件由 b8 读取。D5 副本留存用于追溯。
