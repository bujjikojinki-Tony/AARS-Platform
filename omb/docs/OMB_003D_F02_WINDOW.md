# F-02 窗口诊断

终端启动器留下空的临时输出，尚无可以验收的交互报告。已增加本机诊断窗口，复用原硬件签名和取消测试。

在访达双击交付目录中的 `AARS-F02-窗口诊断.app`，然后点击「开始诊断」。窗口会显示正在检查的项目。若系统允许，先按提示确认两次签名，然后在最后一次系统提示中点「取消」。

进度保存为应用所在目录中的 `AARS_F02_GUI_PROGRESS_*.json`。完成时另存 `AARS_F02_INTERACTIVE_*.json`，可从窗口中打开交付目录。每次运行分配独立报告标识。

应用使用本地临时签名来组成可运行的诊断包。F-02 的可信审批组件签名、控制通道与公钥登记依然需要现场证据。诊断状态保留 `BLOCKED_APPROVAL_PLATFORM`，不会变更任务或审批记录。
