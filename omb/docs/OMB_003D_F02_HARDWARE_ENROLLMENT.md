# F-02 实机公钥登记诊断

Mac 桌面会话使用 Secure Enclave 临时 P-256 密钥签署一次性登记挑战。隔离 D5 宿主验证了该签名和挑战绑定，将公钥写成未激活候选。真实审批平台仍为 `BLOCKED_APPROVAL_PLATFORM`。

## 实测范围

- 诊断应用生成临时硬件密钥，公钥提供给专用隔离宿主。宿主为新工作区、新数据库实例和测试操作者发出一次性挑战，应用校验域、字段、指纹和期限后，通过 macOS 在场认证取得签名。
- 宿主在数据库事务内验签并写入未激活公钥。再次提交同一证明被拒绝。只读复核使用原始挑战和公钥重新验签，并查询隔离数据库，结果为一条未激活公钥、零条激活公钥、零任务、零审计事件和零审批决定。
- 本轮的预期指纹取自隔离诊断的公钥提议，用于验证流程。生产独立信任配置、具有正式签名身份的对端及实际激活仍待验收。
- 三项软件交换测试分别覆盖有效证明、错误挑战摘要及操作者取消。Swift 与 Python 复核同一登记挑战字节的 SHA-256 一致。业务回归 316/316 通过，四项冻结输入指纹匹配。
