# OMB-003D b8 审批后可用状态

裁决为 `READY_FOR_003D_TRANSACTION_REVIEW`。人工在场审批为 `BLOCKED_APPROVAL_PLATFORM`，003E～003G 为 `HOLD`。

## 行为

- 任务详情及列表按请求时刻核验当前证据授权。批准结果的证据授权到期时，两处均返回 `REVIEW_REQUIRED`。到期判断保持只读，任务版本和审计记录在协调器维护前保持原版本。
- 协调器维护、重启或宿主撤销证据授权时，持久化证据授权变更和任务可用状态。已完成任务保持 `COMPLETED`，其可用状态变化追加 `TASK_USABILITY_CHANGED`，原审批签名摘要及历史决定继续可验证。重复和并发维护仅产生一次同一状态变化。
- 已有签名拒绝决定的结果保持 `UNUSABLE`。旧版撤销记录若把该状态记作 `REVIEW_REQUIRED`，读取时按原拒绝决定判定，历史事件仍按原字节校验。
- 读接口中的可用状态反映请求时的授权，持久化审计版本由协调器更新。在场审批流程继续锁定，测试使用合成证据和临时软件密钥。

- b7 在两项定向回归中复现到期后详情和列表仍可用、撤销后已拒绝结果被降为待复核的问题。b8 全量回归 289/289 通过，含 11 项新增专项测试和 32 项 OMB-002-FIX 历史测试。

- 当前非交互会话无有效代码签名身份，且无法调用在场认证。OpenMausBot 人工审批端到端验收仍待执行。
