# F-02 公钥登记校验

本轮实现隔离的待审登记，业务候选仍为 b9，平台状态为 `BLOCKED_APPROVAL_PLATFORM`。

- 可信宿主负责提供独立的预期公钥指纹，同时绑定操作者 ID、公钥标识、工作区和数据库实例。读取已登记公钥时，审批事务也用该指纹复核数据库内容。
- 登记挑战绑定预期登记信息、策略版本、当前启动会话和 256 位随机值。在 120 秒内用拟登记的 P-256 私钥对登记专用域的消息签名。提交时在同一数据库事务内复查签名、指纹、会话和时间。私钥由签名方持有。数据库仅写入未激活的公钥候选。
- 每个工作区本轮仅可登记第一条候选，重复或并发提交仅有一条能入库。已有登记的覆盖和轮换没有业务入口。
- 测试以隔离 SQLite 和临时软件密钥校验待审登记协议。实际的可信签名组件须完成签名身份验收、受保护的宿主配置以及 Secure Enclave 公钥登记验证。

## 验证结果

68 项聚焦测试通过，包含 18 项新增登记测试。覆盖错误私钥、替换公钥及指纹、跨数据库与跨操作者、策略变化、过期、时钟倒退和登记重放。有效候选保持未激活，任务和审核历史不增加记录。

本机回归 316/316 通过，原有九项 MCP 工具通过实进程验证。四项冻结输入哈希均匹配。审批控制面及真实登记激活仍待验收。
