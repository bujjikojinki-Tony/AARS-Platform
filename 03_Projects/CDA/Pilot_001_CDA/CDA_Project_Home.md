## 2. Project Purpose

This project is a bounded pilot established to validate whether AARS Research OS vNext can support structured CDA research.

The pilot focuses on:
- concept structuring
- taxonomy stabilization
- layer validation
- roadmap generation
- reusable knowledge capture

This project does **not** yet aim to:
- produce a final full framework
- complete journal submission by default
- build a production system
- expand to full domain closure

## 5. Current Baseline Judgment

## What Is Stable
- CDA is treated as the core domain concept
- Digital Asset is treated as the broader parent concept
- Criticality is treated as an evaluation concept
- Dependency and System Function are treated as structural concepts
- AARS governance concepts remain separate from CDA domain content
- The 3-paper roadmap is structurally non-overlapping

## What Remains Open
- exact placement of `Model`
- exact placement of `Digital Twin`
- long-term refinement of the `Criticality / Risk / Mission Impact` boundary
- future domain application focus for Paper 3
