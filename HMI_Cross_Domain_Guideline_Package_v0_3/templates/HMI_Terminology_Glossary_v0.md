# HMI Terminology Glossary v0

| Term | Abbreviation | Definition | Allowed UI Label | Forbidden Synonyms | Domain | Example |
|---|---|---|---|---|---|---|
| Human-Machine Interface | HMI | 人与机器系统交互的界面 | HMI | UI only | General | 工业监控台 |
| Human-System Interface | HSI | 人与复杂系统之间的接口 | HSI | HMI 混用需说明 | Nuclear | 核电主控室 |
| Alarm | - | 需要用户关注或处置的异常状态 | Alarm | Message | Alarm Management | A3 告警 |
| Degraded Mode | - | 系统能力下降但未完全失效的状态 | Degraded | Error only | Safety Critical | 数据降级 |
| Latest Stable View | LSV | 最近经过验证、可作为判断基准的稳定状态 | Latest Stable View | Latest Data | AARS | 稳定视图 |
| Recovery Path | - | 异常或降级状态下恢复到可控状态的路径 | Recovery Path | Retry only | Safety Critical | 数据恢复路径 |
| Action Gate | - | 操作执行前的条件、风险、权限和确认检查 | Action Gate | Button state only | HMI | 执行前置检查 |
| AI Recommendation | - | AI 基于输入与证据给出的建议 | AI Recommendation | Auto decision | AI Interface | 机会市场推荐 |
