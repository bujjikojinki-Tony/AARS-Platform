# Health_Snapshot_Template

## 1. Purpose

This template provides the standard structure for health snapshots in AARS.

It is intended to:
- summarize current bounded condition
- support review and next-step judgment
- clarify whether continuation is safe
- provide a state anchor for stable view and recovery logic

This is a health snapshot template.
