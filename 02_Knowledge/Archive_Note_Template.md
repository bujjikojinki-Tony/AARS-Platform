# Archive_Note_Template

## 1. Purpose

This template provides the standard structure for archive notes in AARS.

It is intended to:
- record why an asset is being archived
- preserve historical traceability
- distinguish archived material from active or frozen material
- support later historical review without confusing current operation

This is an archive note template.

---

## 2. Recommended File Name

Examples:
- `Pilot_001_CDA_Archived_Baseline_01.md`
- `AARS_System_Archived_Baseline_01.md`
- `ARCHIVE-CDA-CASE01-01.md`
