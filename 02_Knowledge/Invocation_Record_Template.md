# Invocation_Record_Template

## 1. Purpose

This template provides the standard Markdown structure for an AARS invocation record.

It is intended to:
- record that a capability was actually used
- preserve execution traceability
- connect project, case, capability, and output
- support review and object-chain integrity

This is an invocation template.
