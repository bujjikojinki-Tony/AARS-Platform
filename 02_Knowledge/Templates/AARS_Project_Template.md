# AARS_Project_Template

## 1. Purpose

This template provides the standard starting structure for an AARS project.

It is intended to:
- reduce ambiguity when opening a new project
- standardize how projects are framed
- ensure minimum boundedness from the start
- support faster GPT/Codex-assisted setup
- improve cross-project comparability

This is a template, not a filled project file.

---

## 2. Use Rule

Use this template when:
- starting a new AARS project
- converting an informal topic into a governed project
- opening a new pilot
- re-framing a drifting workstream into a bounded project

Do not use this template as a substitute for later review, stable-view, or freeze logic.

---

## 3. Recommended File Name

Typical names include:
- `Project_Charter.md`
- `Pilot_001_<Domain>_Project_Charter.md`
- `<Domain>_Project_Charter.md`

If the project is a pilot, include the pilot identifier.
