# IEC 61508 Functional Safety Guide

## 1. Purpose

This guide explains how to use IEC 61508 as the generic functional safety reference for E/E/PE safety-related systems.

## 2. When to use IEC 61508

Use IEC 61508 when the task is about:

- safety functions
- hazard and risk basis
- SIL logic
- lifecycle integrity
- systematic capability
- validation
- modification and maintenance effects

## 3. Core rule

SIL applies to a safety function, not simply to an individual device.

## 4. Lifecycle view

1. Identify hazards and risk-reduction needs.
2. Define safety functions.
3. Assign integrity expectations.
4. Define safety requirements.
5. Implement design and software under control.
6. Verify and validate the function.
7. Define operation and maintenance controls.
8. Control modifications.

## 5. Evidence themes

- hazard basis
- safety function definition
- integrity basis
- requirements
- design and architecture
- implementation evidence
- validation evidence
- operation and maintenance constraints
- change impact evidence

## 6. Common failure modes

- device-only SIL claims
- weak safe-state definition
- unclear response-time basis
- systematic capability ignored
- lifecycle closure skipped

## 7. Engineering use note

Use IEC 61508 as the generic backbone. If the work is process-industry SIS / SIF specific, IEC 61511 is usually the more operational lifecycle reference.
